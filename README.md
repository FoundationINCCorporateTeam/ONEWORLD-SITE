# ONEWorld Website

A modern, multi-page website for ONEWorld - an AI-powered Roblox customer support platform featuring ONEWorld Sentri chatbot.

## 🌐 Pages

- **index.html** - Homepage with hero section, features preview, and social proof
- **features.html** - Comprehensive features showcase with detailed descriptions
- **ai-model.html** - AI technology explanation with interactive demo
- **pricing.html** - Transparent pricing with 3-tier structure and comparison
- **demo.html** - Request demo form with validation

## 🎨 Design Features

- **Glassmorphism UI** - Modern frosted glass aesthetic throughout
- **Cold/Tech Theme** - Deep blue and cyan color palette
- **Fully Responsive** - Mobile-first design (mobile, tablet, desktop)
- **Smooth Animations** - Scroll reveals, hover effects, and transitions
- **Self-Contained** - All CSS and JavaScript embedded in each HTML file

## 🛠️ Technology Stack

- **HTML5** - Semantic markup
- **Tailwind CSS** - Via CDN (v3.x)
- **Vanilla JavaScript** - No frameworks required
- **Font Awesome** - Icon library
- **Google Fonts** - Inter font family

## ✨ Key Features

### Navigation
- Sticky header with glassmorphism effect
- Active page highlighting
- Mobile hamburger menu with slide-in animation
- Consistent across all pages

### Interactive Elements
- Scroll-triggered animations
- Animated counters (index.html)
- Interactive chat demo (ai-model.html)
- Form validation (demo.html)
- Monthly/yearly pricing toggle (pricing.html)
- Accordion FAQs

### Design System
- Color Palette: Deep blues (#0A1628, #1E3A8A) and cyans (#06B6D4, #0891B2)
- Glass effects with backdrop-blur

- Card hover effects with lift and glow
- Smooth transitions

## 📱 Responsive Breakpoints

- **Mobile**: < 640px (single column, stacked layout)
- **Tablet**: 640px - 1024px (2-column grids)
- **Desktop**: > 1024px (full multi-column layouts)

## 🚀 Getting Started

Simply open any HTML file in a modern web browser. No build process or dependencies required!

```bash
# Open the homepage
open index.html
# or
python -m http.server 8000
# Then visit http://localhost:8000
```

## 🔧 Customization

All styling is embedded in each HTML file's `<style>` tag. To customize:

1. Open the HTML file you want to modify
2. Find the `<style>` section in the `<head>`
3. Update colors, fonts, or other styles
4. Save and refresh the browser
